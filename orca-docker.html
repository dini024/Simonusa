What is ORCA DOCKER?

DOCKER adalah algoritma docking berbasis energi di ORCA untuk mencari orientasi/pose host–guest dan membentuk kompleks pertemuan. Ini bukan Docker Desktop/container. ORCA DOCKER menerima satu struktur host di bagian geometri input dan struktur guest melalui berkas XYZ terpisah. Metode GFN2-xTB cocok untuk contoh molekul kecil; GFN-FF dapat dipertimbangkan untuk sistem besar.

DOCKER is ORCA's energy-driven docking algorithm for exploring host–guest orientations and encounter complexes. It is not Docker Desktop/a software container. ORCA DOCKER takes the host geometry in the input and a separate guest XYZ file. GFN2-xTB is suitable for small-molecule examples; GFN-FF may be considered for larger systems.

Official reference: FACCTs ORCA 6.0 — Automated docking (DOCKER).
